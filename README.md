# パーツポン！工場 / Parts Pop Factory

パーツポン！工場（Parts Pop Factory）― スマホのブラウザで遊べる物理パズルゲーム（Ver1.0.0）

Parts Pop Factory is a physics puzzle game you can play in your phone's browser (Ver1.0.0).

床のせり上がり（完成台数あたりの上昇）を一段緩めました（floorRise.perCar 0.02→0.015）。その他の難易度・物理は同じです。
The rising floor is one step gentler (floorRise.perCar 0.02→0.015). Other difficulty and physics are unchanged.
