# Quality Rush 効果音（あーと自作・numpy合成、商用可、クレジット不要）
ogg と mp3 の両方あり。
| ファイル | 使う場面 |
|---|---|
| drop | 部品を離したとき（小さめ） |
| merge | 合体（青・緑） |
| merge_big | 合体（橙・黄・赤など後半） |
| complete | 完成車：セル→エンジン始動＋チャイム。flash.webp と一緒に |
| coin | 売上加算（coin.webp を飛ばす） |
| defect_putter | 不良車の出庫：プスンプスン→ボンッ。黒煙 fx と一緒に |
| discard | ゴミ箱に捨てた |
| complaint | クレーム発生（complaint_tag.webp と一緒に） |
| floor_rise | 床がせり上がる ゴゴッ |
| warning | 箱があふれそう |
| mechanic_in | 整備士が落ちてくる |
| repair | 修理完了（sparkle_1-4 と一緒に） |
| level_up | レベルアップ |
| game_over | ゲームオーバー |
推奨音量: 0.5〜0.7。drop/merge は連打されるので 0.4 くらい。
